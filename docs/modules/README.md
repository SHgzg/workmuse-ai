# 业务模块文档索引

本目录用于保存各业务模块的详细需求。总体产品边界以 `docs/product/product-requirements.md` 为准。

## 模块清单

| 模块 | 核心职责 | 关键依赖 |
| --- | --- | --- |
| 会议 | 会前准备、记录、纪要、观点、决策和行动项 | 材料、搜索、任务 |
| 文件柜 | 材料存储、分类、版本、权限和关联 | 搜索、项目 |
| 搜索溯源 | 全文检索、自然语言查询和原文定位 | 材料、权限、AI |
| 目标 | 指标、目标值、里程碑和进度 | 任务、成果 |
| 任务 | 行动分配、依赖、进度和验收 | 目标、会议、建议 |
| 成果 | 交付物、数据、证明材料和审核 | 目标、任务 |
| 差距分析 | 目标与成果对比、风险和瓶颈 | 目标、成果、AI |
| 知识库 | 已确认知识、来源和生命周期 | 会议、文件、搜索 |

## 模块文档模板

新增模块文档时包含：

1. 模块目标和非目标；
2. 用户角色与场景；
3. 功能范围和业务规则；
4. 页面与关键交互；
5. 数据对象与字段；
6. 权限、隐私与审计；
7. AI 行为、来源和纠错；
8. 异常与边界情况；
9. 验收标准；
10. 当前状态、待定问题和关联文档。

只有模块规则复杂到总体需求无法清晰承载时，才拆分独立文档，避免复制相同内容。
