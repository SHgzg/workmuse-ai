# ADR 0002：桌面端默认使用软件渲染

## 状态

已采用。

## 背景

WorkMuse 是文档与数据密集型桌面应用，不依赖 3D、视频特效或高帧率画布。真实 Electron 启动验证中，当前 Windows 环境的 GPU 子进程因图形运行库不兼容连续退出，最终导致整个应用终止。这类问题也常见于远程桌面、虚拟机和精简企业镜像。

## 决策

主进程在 `ready` 前调用 `app.disableHardwareAcceleration()`，统一使用软件渲染。应用启动初始化增加顶层错误捕获；本地数据目录、认证、业务存储或 Core 初始化失败时显示明确错误并退出，不留下无响应空窗口。

## 影响

- 提高远程桌面和缺少兼容 GPU 运行库环境中的稳定性。
- 可能增加少量 CPU 使用并降低复杂图形性能；当前 UI 工作负载可接受。
- 如果未来引入大量视频渲染或可视化，需要在目标硬件矩阵中重新评估，并提供经过验证的可配置策略。
