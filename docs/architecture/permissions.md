# 身份与权限边界

## 当前单机模式

当前版本是单机、单账户、私有工作区。首次使用邮箱和至少 8 位密码创建本地账户；密码通过随机盐和 scrypt 派生后保存，明文密码不落盘。应用重启后会话失效，需要重新验证。

主进程对 Core、搜索、资料打开、设置和全部业务数据 IPC 执行登录门禁。Renderer 自己切换页面或修改内存状态不能绕过门禁。

所有资料仍受 AssetStore 和 Worker allowed roots 约束：Renderer 只能提交 checksum 资源 ID，主进程验证原文件存在后才能打开或写入业务来源关系。

## 未启用的身份方式

微信扫码和企业 SSO 需要真实身份提供商、回调地址、服务端票据校验和账户绑定。在这些条件完成前 UI 明确显示不可用，不生成演示二维码或模拟成功状态。

## 团队模式前置条件

当前账户不能代表团队权限。启用共享空间前必须增加：

- 工作区成员、角色和资源级授权；
- 搜索、预览、AI 上下文、导出的一致权限过滤；
- 权限变更与敏感操作审计；
- 本地账户到远程身份的可回滚绑定与迁移。
