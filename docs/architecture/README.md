# 架构文档索引

架构文档描述系统如何满足产品需求，不重复业务需求正文。

架构内容应按实际实现逐步补充：

- `system-architecture.md`：进程、服务、数据流和部署边界；
- `data-model.md`：项目、会议、材料、观点、目标、任务、成果及关系；
- `search-architecture.md`：解析、索引、召回、排序、引用和原文定位；
- `permissions.md`：授权模型、搜索过滤、AI 问答和审计；
- `ai-design.md`：模型职责、结构化输出、证据约束、失败回退和评估。

涉及安全边界、数据格式、存储方案或难以撤销的技术选择时，同时在 `docs/decisions/` 添加决策记录。
