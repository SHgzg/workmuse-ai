# WorkMuse UI 规划

## 1. 设计目标

界面应帮助用户快速完成四件事：找到原始信息、掌握目标和成果、识别差距与风险、把 AI 建议转为行动。整体气质是专业、安静、可信的工作台，而不是复杂的数据后台。

## 2. 信息架构

桌面端左侧一级导航：

- 首页
- AI 助手
- 项目
- 会议
- 文件柜
- 目标
- 任务
- 成果
- 知识库
- 通知
- 团队与设置

顶部固定区域提供空间切换、全局搜索、快速新建、通知和个人菜单。快速新建支持灵感、项目、会议、材料、目标、任务和成果。

标准页面使用“导航 + 主内容 + 可收起详情/AI 面板”。会议回放、文件阅读和搜索溯源使用“目录/结果 + 原始内容 + 关联与操作”的三栏布局。

## 3. 核心页面

### 3.1 首页工作台

- 今日最重要事项与快速记录入口；
- 进行中目标、今日任务、待确认纪要和风险项目；
- 目标值、当前成果、差距、趋势与下一步建议；
- 最近会议、文件、成果和搜索；
- 右侧 AI 建议与一键创建任务。

### 3.2 AI 助手

- 左侧为历史对话和项目分组，中间为对话，右侧为资料范围和引用来源；
- 提供“搜索观点、查找决策依据、分析进度、比较目标与成果”等快捷入口；
- 回答明确标识事实、摘要、推断和待确认信息；
- 关键结论旁提供查看来源、保存知识和转为任务操作。

### 3.3 项目中心

- 项目列表支持卡片、列表、状态和负责人视图；
- 项目详情顶部展示状态、成员、期限、进度和风险；
- 详情包含概览、目标、任务、会议、文件、成果、决策和动态页签；
- 概览集中展示目标成果对比、里程碑、风险和建议。

### 3.4 会议中心

- 会议列表按项目、日期、参与人、状态和待办筛选；
- 创建流程包括基本信息、参与人、目标议程、关联内容、材料和记录方式；
- 会议详情包含概览、记录、材料、观点、决策、任务和相关会议；
- 记录页左侧为议程与时间轴，中间为播放器和同步转录，右侧为观点、决策、材料与任务。

### 3.5 智能文件柜

- 左侧为全部、最近、收藏、共享、项目、会议、归档、回收站和自定义目录；
- 中间支持列表、网格以及按会议、项目、时间和类型分组；
- 右侧展示文件预览、摘要、版本、权限和关联对象；
- 上传后展示 AI 建议文件名、分类、标签、项目关联及重复版本提示，用户可修正。

### 3.6 全局搜索与溯源

- 搜索框提示“搜索文件、会议、观点、任务，或直接提问……”；
- 左侧按内容类型、时间、项目、发言人和文件类型筛选；
- 中间展示命中内容、上下文、来源、日期以及页码或时间点；
- 右侧预览原文并提供跳转、收藏、对比和追问；
- 观点查询先显示 AI 汇总，再逐条展示原始证据；
- 支持以时间线查看观点的提出、争议、修改和决策。

### 3.7 目标中心

- 目标卡显示目标值、当前值、时间进度、完成比例、差距和风险；
- 创建目标时配置负责人、指标、基准、目标值、期限、里程碑和依据；
- 详情页核心区域对比目标、当前成果、差距和状态；
- 提供指标、任务、成果、差距、建议和材料页签。

### 3.8 任务中心

- 支持我的任务、团队任务、列表、看板、日历和时间线；
- 卡片显示目标、负责人、优先级、期限、状态、预期成果和阻塞；
- 详情显示依赖、子任务、验收标准、当前成果、来源和原始依据；
- 会议生成、目标拆解、灵感转化和 AI 建议使用清晰的来源标识。

### 3.9 成果中心

- 按项目、目标、负责人、类型和审核状态查看；
- 登记成果时填写数据、所属目标与任务、证明材料、质量评价和审核人；
- 详情展示成果预览、目标贡献、关联任务、证据、版本和审核记录。

### 3.10 差距与优化

- 顶部展示目标完成度、时间进度、预计完成时间、最大差距和关键瓶颈；
- 分类展示数量、质量、时间、资源、执行、协作和信息差距；
- 每项结论可查看数据来源和计算依据；
- 优化建议显示优先级、预期影响、成本、步骤、风险及“采纳并创建任务”；
- 追踪优化前后指标和实际改善程度。

### 3.11 知识库与通知

- 知识库按专题、项目、会议结论、决策和审核状态组织；
- 知识详情保留正文、原始出处、关联对象和修改历史；
- 通知按待处理、提醒和系统消息分类，并在卡片内提供直接操作。

## 4. 通用组件

- 全局搜索、筛选器和快速新建；
- 项目、会议、文件、目标、任务、成果和建议卡片；
- 进度条、风险标签、指标对比表和时间轴；
- 音视频播放器、同步转录和文档预览；
- 来源引用卡、权限选择器、评论与活动记录；
- 上传/解析进度、加载、空、错误、无权限和离线状态。

## 5. 视觉规范

- 中性色为主体，蓝紫色代表品牌和 AI；绿色、黄色、红色分别表达正常、关注和风险；
- 状态同时使用文字、图标和颜色，避免只依赖颜色；
- 所有 AI 内容显示生成标识、生成时间、数据范围、来源数量、查看依据和纠错入口；
- 关键数据突出，次要元信息弱化，长内容优先渐进展开。

## 6. 响应式策略

- 桌面端提供完整三栏、文件管理和复杂分析能力；
- 平板端收起导航，三栏降为双栏，详情使用侧滑面板；
- 移动端优先首页、灵感、任务、会议、上传、通知、观点查询和快速确认；
- 复杂配置、文件整理及多维对比优先在桌面端完成。

## 7. 首批原型与 MVP 页面

优先制作首页、项目详情、会议列表、会议详情、会议回放、文件柜、搜索结果、原材料溯源、目标详情、任务详情、成果登记、差距分析与优化建议共 12 个核心页面。

验收重点是完整走通：

> 会议和材料进入系统 → 信息可搜索和溯源 → 形成目标与任务 → 登记成果 → 分析差距 → 执行优化建议
